# Habiba Mohshina — Academic Website

A clean, lightweight, no-build academic website for GitHub Pages.

Repository:
`habibamohshina03-cpu.github.io`

Upload the contents of this folder to the ROOT of that repository (not the ZIP file).

Files:
- `index.html` — website
- `assets/style.css` — design
- `assets/profile.jpg` — profile photo
- `files/Habiba_Mohshina_CV.pdf` — CV

No Ruby, Jekyll, npm or other software is required. GitHub Pages can serve this static site directly.

Privacy: the site omits the full residential address and referee email addresses.
